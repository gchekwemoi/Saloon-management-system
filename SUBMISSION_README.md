# Coursework submission

Read [README.md](README.md) for setup, current features, examples and limitations.
Read [PROJECT_REVIEW.md](PROJECT_REVIEW.md) for OOP presentation notes and the final review.
Read [SECURITY_AND_CORRECTIONS.md](SECURITY_AND_CORRECTIONS.md) for accounts and audit behaviour.

Start with `python -m streamlit run app.py` and test with `python -m pytest -q`.
Install `requirements-dev.txt` first. The app uses authenticated accounts, not a role selector.
Do not submit local credentials, SQLite databases, backups or virtual environments.
